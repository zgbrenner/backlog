# Regenerate a fully hash-pinned Windows lock with pip-compile on the release

# NOTE: the five markitdown extras below are the document parsers, not a
# convenience. Base `markitdown` requires only beautifulsoup4,
# charset-normalizer, defusedxml, magika, markdownify and requests -- every
# Office/PDF reader is an extra, so without these a .docx raises
# FileConversionException and the file quarantines. `xls` earns its place the
# same way: routing.rs puts application/vnd.ms-excel in NATIVE_TYPES, and
# markitdown's XLS branch is pd.read_excel(engine="xlrd"), so without it every
# legacy .xls in the backfill quarantines too. Still NOT `markitdown[all]`:
# that additionally pulls azure-*/youtube-transcript-api/pydub/
# speechrecognition, none of which this app uses.
# NOTE: torch/transformers/sentence-transformers/gliclass are deliberately
# absent. This is the slim, torch-free sidecar profile: the classify,
# salience, and ettin_spans ops degrade to sensible defaults in
# convertd.py when those libraries (or their models) are unavailable, so
# convert/OCR/langid/naming keep working without ~450 MB of PyTorch. See
# docs/DEPENDENCY_COMPATIBILITY.md and docs/IMPLEMENTATION_STATUS.md.
markitdown[pdf,docx,pptx,xls,xlsx]>=0.1.1,<0.2
pypdfium2>=4.30,<5
